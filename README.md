# figghost

An all-in-one macOS menu bar app written in Rust. It combines three tools in one process, with a pure AppKit interface through the `objc2` crates and no Dock icon.

- Scrolling (like Mos): smooth mouse-wheel scrolling, a reverse direction for external mice only, and per-app settings.
- Clipboard history (like Maccy): text, links, code, images and files, instant search, pinning, and a popup at the pointer.
- Notch panel (like OneNotch): a black shape that grows out of the top edge of the screen on hover. It has three tabs: the clipboard, a file shelf and a media tab. It also provides window tiling and an optional volume indicator.

The interface is available in English and Vietnamese.

## Features

Scrolling

- Wheel events are swallowed and replaced by smooth pixel-based scroll frames that add up to the same distance. Trackpad and Magic Mouse events, events the app posted itself, and events with a modifier held (Shift, Control, Option, Command) pass through untouched.
- Per-app overrides: smooth scrolling can be turned off for one application from the menu.

Clipboard

- Records text, links, code, images and file lists. Items marked concealed, transient or auto-generated by the source app, and password managers, are never stored.
- SQLite with an FTS5 trigram index. Search ignores case and Vietnamese diacritics and falls back to fuzzy matching. Filters: `@image @link @code @text @file @pin`.
- Popup at the pointer with a global shortcut (default Command+Shift+C) that does not take focus from the app in use. Enter pastes into that app. Option+P pins, Option+Delete removes.

Notch panel

- Hovering the top edge of the screen opens it (0.12 s delay, closes after 0.35 s). Clicking it focuses the search field. Command+1, 2, 3 switch tabs.
- Clipboard tab: the same list as the popup.
- Shelf tab: drop files from any app to keep them handy. The shelf stores paths only, never copies. Drag a tile out to copy the file elsewhere, double-click or press Enter to open it, press Delete to remove it from the shelf. Dragging files onto the notch opens it and is meant to switch to this tab (see Not verified).
- Media tab: previous, play/pause and next buttons that press the real media keys, and the current track for Music and Spotify. The track is polled only while the tab is visible.

Window tiling

- 13 layouts (halves, quarters, thirds, maximize, center) on global shortcuts, using the Accessibility API. Defaults: Control+Option plus Left, Right, Up, Down (halves), U, I, J, K (quarters), Return (maximize), C (center), D, F, G (thirds). Override or disable each layout in the config.

Volume indicator (off by default)

- Replaces the system volume HUD with one that hangs from the top edge. Volume Up and Down move along 16 marks (64 with Shift+Option held), the Mute key toggles, and a volume key also lifts a mute. It needs Accessibility access. If the output device has no software volume (for example HDMI or DisplayPort speakers), the keys are left to the system. The system feedback sound is not played while this is on.

Menu bar item ("Fig")

- Accessibility prompt (shown only while access is missing), global smooth and reverse toggles, smooth scrolling for the frontmost app, volume indicator, open the clipboard, clear unpinned history, launch at login, open the config folder, quit.

## Status

Verified on this machine (macOS 27, Apple silicon Mac mini, one external 1920x1080 display), with a private instance so that the real clipboard and settings were never touched:

- Scrolling pipeline with synthetic wheel events: swallowed and turned into frames with the exact total distance and phases (median frame interval 8 ms at 120 Hz). The decision per event takes under 20 microseconds (a test), against a 1 ms budget.
- Clipboard capture, filtering, search and the popup, including the global shortcut, arrows, pin, delete and Escape.
- Real paste: Command+V reached a controlled target app about 145 ms after Enter, after waiting for keyboard focus to leave the popup.
- Notch hover open and close, including a pointer pushed against the very top row, and the three tabs.
- Shelf: a file dragged from another process onto the notch and dropped on the shelf was stored in `shelf.json`.
- Tiling through the real shortcuts on a controlled target window.
- Menu: the per-app smooth toggle writes the config and updates its check mark.
- Volume indicator: with synthetic volume and mute keys, each key changed the real output volume by exactly one step (no double handling by the system), the mute state toggled, and the indicator appeared. The system volume was restored afterwards.
- Media tab: layout and display with a sample track. The player scripts compile, and the script never launches a player that is closed.
- Languages: English and Vietnamese string tables, with a render check of the English interface.
- Idle resources of the final build: 0.0% CPU and a 21 MB footprint (peak 22 MB, from the `footprint` tool; `ps` reports about 100 MB RSS because it counts shared system framework pages).
- Quality gates: `cargo test --workspace`, `cargo clippy --workspace --all-targets -- -D warnings` and `cargo fmt --check` are clean.

Not verified:

- Physical volume keys, and the Shift+Option fine step.
- Media control and track display against a playing Music or Spotify. Media keys were checked only through an observer tap, because a play key can start a player.
- Trackpad and Magic Mouse input, and the feel of the default scrolling parameters (36 px per line, 360 ms).
- Typing Vietnamese with Telex or VNI in the search field. The navigation keys are ignored while an input method has marked text, which is checked in-process only.
- A Mac with a hardware notch: this machine has none, so that branch is covered by geometry tests only.
- That dragging a file onto the collapsed notch switches straight to the shelf tab. In the one end-to-end run, the notch opened on the clipboard tab, and the drop still reached the shelf once the pointer moved down into the window.
- Dragging a tile out of the shelf into another app (only an in-process drag between two panels was checked).
- Launch at login from the packaged app, the pasteboard privacy prompt of recent macOS versions, and notarization.
- That launching the app never steals focus. A fix is in place (the panel is created after launch finishes) but the final end-to-end check was skipped.

## Languages

The `language` setting accepts `auto` (default), `en` or `vi`. `auto` takes the first system language that has a translation and falls back to English. The language is chosen once at startup. To add one, add a variant to `Language` in `crates/app-ui/src/i18n.rs`: every string is a method with an exhaustive `match`, so the compiler lists what still needs translating.

## Repository layout

- `crates/macos-sys`: all `unsafe` code and FFI: panels, event tap, event posting, Carbon hotkeys, pasteboard, app tracking, CoreAudio, the list, popup, notch, shelf, media and volume views, status item.
- `crates/core-mouse`: the scroll engine (source classification, decision, smoother, frame pump).
- `crates/core-clipboard`: history core (SQLite store, search, content classification, ignore policy).
- `crates/core-window`: tiling layouts as pure geometry.
- `crates/app-ui`: composition root, configuration, language tables and the feature controllers.
- `scripts/bundle.sh` builds `Figghost.app`; `scripts/check-focus.sh` checks that launching does not change the frontmost app.

## Build and run

Rust is installed with rustup into `~/.cargo`. Keep the build directory outside the project:

    . "$HOME/.cargo/env"
    export CARGO_TARGET_DIR="$HOME/Library/Caches/figghost-target"
    cargo test --workspace
    cargo clippy --workspace --all-targets -- -D warnings
    scripts/bundle.sh            # creates dist/Figghost.app

Accessibility access is tied to the code signature of the app. The default ad-hoc signature changes on every build, so access has to be granted again. To keep it, create a local code-signing certificate in Keychain and run `SIGN_IDENTITY="Certificate name" scripts/bundle.sh`.

Accessibility is needed for smooth scrolling, automatic paste, window tiling and the volume indicator. Without it the app still runs: the popup and the notch work, items are copied to the clipboard for a manual paste, and the scroll engine starts by itself once access is granted.

## Configuration

`~/Library/Application Support/Figghost/config.json`, created the first time a menu item is toggled. Missing values use defaults, out-of-range values are clamped, and an unreadable file is moved to `config.json.bad` instead of being overwritten.

    {
      "language": "auto",
      "hotkey": "cmd+shift+c",
      "auto_paste": true,
      "volume_hud": false,
      "history_limit": 500,
      "ignored_apps": ["com.example.vault"],
      "mouse": {
        "smooth": true,
        "reverse": false,
        "step_px": 36.0,
        "speed": 1.0,
        "duration_ms": 360.0,
        "fps": 120.0,
        "apps": { "com.example.game": { "smooth": false } }
      },
      "tiling": {
        "enabled": true,
        "shortcuts": { "left": "ctrl+opt+left", "center": "" }
      }
    }

A shortcut needs at least one modifier, except function keys (f1 to f20). An empty shortcut turns that layout off. Layout names: `left right top bottom top_left top_right bottom_left bottom_right maximize center first_third center_third last_third`.

Environment variables: `FIGGHOST_HOME` changes the data directory, `FIGGHOST_PASTEBOARD` uses a named pasteboard instead of the real clipboard (both are for tests), and `FIGGHOST_TRACE=1` prints a timeline to stderr.

## Data and privacy

History lives in `~/Library/Application Support/Figghost` (`history.sqlite`, an `images` folder, `shelf.json`), with directory mode 0700 and no encryption. Items flagged by the source app and password managers are skipped, but a password copied from another source can still be stored: use `ignored_apps` or clear the history from the menu.

## Development tools

Programs in `crates/*/examples`. Some of them post real input events, so read the warnings.

- `core-mouse/probe`: runs the scroll engine with a recording output. It swallows the real mouse wheel while it runs.
- `macos-sys/loopback`: checks the scroll, paste and media or volume key posting paths with an observer tap that swallows what this process posts.
- `macos-sys/render_ui`, `notch_demo`, `hud_demo`: draw the list, the notch (set `PAGE=1` or `PAGE=2` for other tabs, `NO_OPEN=1` to test hover) and the volume indicator.
- `macos-sys/layout_check`: opens the notch with three tabs, where two were added while it was collapsed, and checks that every page lies inside the window and the tab bar is centred. Exits with status 1 on a problem.
- `macos-sys/volume_check`: reads the output volume through CoreAudio and writes the same values back.
- `macos-sys/post_key`: presses a media or volume key at the HID level. Warning: when delivered, the system acts on it. It changes the real volume, and a play key can start Music.
- `macos-sys/key_probe`: prints every system-defined key event the session sees and lets them through (so the system still acts on them).
- `macos-sys/drag_source`, `dnd_check`, `paste_target`, `check_composition`, `tile_check`: a draggable file for cross-process drops, an in-process drag and drop check, a window that records the keys it receives, an input method guard check, and a tiling check on the example's own window.

## Technology choices

The interface uses AppKit through `objc2`, not GPUI or Tauri. The search field must accept Telex and VNI typing, which `NSSearchField` handles natively while GPUI would need a custom input field. Non-activating panels, mouse tracking and the app lifecycle are proven in this repository, and idle memory stays low. SQLite is the system library (with FTS5 and the trigram tokenizer), not a bundled build.
