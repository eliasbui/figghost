- Network: the diagram opens in a window of its own, with a close button, on a dotted grid. Each connection is a circle and each app a box you can move anywhere; where you put them is kept.
- Wire Wi-Fi to Ethernet (or the other way) to combine them: a big circle holds both. An app wired to the big circle uses both connections, to a small circle only that one.
- Every app that uses the network appears on the diagram by itself, wired to the connection it is using, and stays there after it stops.
- Opening the Network page no longer slows the app: the connections are listed off the main thread and the wires no longer animate without end.
